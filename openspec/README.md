# OpenSpec contracts and historical records

[Current specifications](specs/) define supported behavior under the latest Human
scope and source-supported reconciliations. They are distinct from historical
proposals and unfinished acceptance records.

All 104 changes active before 2026-10-30 were archived with their complete internal
structure and original task states. The [disposition index](changes/archive/2026-10-30-archive-index.md)
maps every source to its archive; the [evidence index](changes/archive/2026-10-30-evidence-index.md)
retains exact immutable reports and shared ownership. Earlier archives remain intact.

Archival is not implementation or acceptance. No historical execution queue is
activated, no conflicting deltas were merged wholesale, and retired source-SYNC
features are not restored. New behavior requires a new focused change and the
usual source, realtime, ownership and verification safeguards.
