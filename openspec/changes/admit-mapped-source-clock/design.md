piecewise affine B/S geometry. LoaderEventDelivery retains actual original Native
source qualification and map artifact custody. CapturedPadStart and the existing
ordinary/global start work own launch admission. SourcePlayback, SourceReadPlan,

## Canonical addressing and copied spans

For a normal mapped loop use
`s(n)=loaded_Fs*S(b0+mod(M(n)+phase,L))`.
Freeze the actual intended output address and existing master-tempo epoch. Never
substitute callback-now for already buffered Native input. Local physical rate
is the derivative of this same trajectory, excluding the wrap discontinuity; do
not multiply a second scalar BPM ratio into the mapped source clock.

Retain immutable geometry and qualified artifact/source pins separately from the
fixed Copy cursor, checkpoint and read receipt. A copied segment must evaluate
with the canonical arithmetic and fixed global anchors so callback partitioning
cannot become a new rounding origin. Split reads at map/loop/master-epoch
boundaries. If multiple fractional knots lie between adjacent output frames,
reevaluate the exclusive next endpoint canonically and use bounded lookup rather
than walking an unbounded number of knots. Historical receipts contain genuine
read coordinates and identity markers, not executable ownership.

## Musical extent and physical coverage

An explicit mapped auto-bars resolution keeps L=4*bars exactly and obtains its
unrounded endpoint from S(B(actual start)+L). Existing Residency must prepare and
acknowledge the corresponding rounded physical window before its launch claims.
Do not derive L back from the rounded or old scalar endpoint. A truly manual
physical end instead preserves that marker and uses B(end)-B(start). Supported
whole-interval coverage and required meter are admitted off realtime. The map's
metadata rate alone does not prove the current loaded playback rate.

## Staging and truthful limitations

First integrate actual mapped addressing and lifecycle through ordinary launch
and the dry render route. This is a concrete prerequisite, not full SYNC. Key
Lock OFF with nonzero pitch has constant Native pitch h and is mathematically
supported; its existing fixed-h preparation must receive the mapped chronology.
Key Lock ON requires h/r through the actual Native block parameter protocol.
The current one-pitch-per512-input-block limitation cannot be solved by receipt
metadata or reader splitting alone. Unsupported or not-yet-integrated tuples
retain prior effective audio and expose a precise pending/refused result.

The first productive envelope is deliberately admitted only with Key Lock OFF,
zero total pitch, speed one, BPM Lock ON, a valid stable actual master epoch and
E=T. It proves original ordinary/global/MIDI routing and genuine mapped reads.
Pause/seek, mapped stem transactions, prepared Native/FIFO tuples, master-epoch
replacement and delayed mapped birth require their own continuation integration;
they refuse before effective mutations. These are explicit remaining gates,
never a permanent product restriction. `PitchPadProjection.sync` is the existing
BPM Lock projection; the new mapped SYNC request is the additional control the
Human requested and is not silently derived from or substituted for BPM Lock.

An original CapturedPadStart retains qualified map geometry through its Work and
effective voice. The existing PadStartTarget retirement payload transfers its
last owner off realtime. Admission adds one reservation per actual retained mapped
owner to the established scalar budget, preserving scalar-only retry thresholds.
Historical Copy spans contain sufficient immutable canonical coefficients for
their actual read intervals. Their history guards and PCM/reader pins authorize
replay; future lookup through a whole map additionally borrows its original
qualified owning geometry. A numerical marker never supplies either permission.

Map/source/loop/selection changes, cancellation, stale work and retirement
pressure must fence claims through the original admission/prepare/claim path.
An already effective immutable old trajectory may remain audible until a complete
replacement is admitted. Do not weaken source guards to retain a stale request.

## Validation boundary

Exercise real qualified capture, ordinary/global launch, Mixer reads, actual-read
journal and preparation/catchup with fractional map knots, distant landmarks,
long vocal versus repeated short-loop geometry and irregular caller partitions.
Check exact canonical endpoints, independent copied state, old/new source/map
failure and retirement saturation. These are software addressing/lifecycle
proofs; they do not establish pitch quality, hearing or complete SYNC acceptance.
