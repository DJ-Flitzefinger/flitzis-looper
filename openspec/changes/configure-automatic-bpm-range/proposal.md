## Why

The Human wants an optional configurable BPM range, disabled by default. An
explicit range can resolve half/double interpretation when independently checked
automatic candidates support both units. Existing broad detection stays the
default, including its unresolved accuracy cases.

## What Changes

Persist a validated automatic-analysis range and snapshot it when each request is
admitted. Retain an already in-range primary value. An outside successful neural
v4/v5 value may select one independently admitted QM half/double candidate within
the requested bounds. Otherwise report no supported BPM for that new request.
Existing PAD values and explicit manual/Tap controls remain authoritative.

## Impact

Settings, Native request snapshots, bounded optional QM analysis, strict saved
method provenance and current automatic guidance. No new estimator, model,
decoder, clock or publication owner. Range-assisted results do not establish the
default-OFF corpus accuracy target.
