## ADDED Requirements

### Requirement: Raw review collects explicit quarter labels before building
The Source Map Raw inspector MUST provide English controls to add/update and
remove at most 64 explicit Raw-index/quarter-coordinate labels and build through
the original-candidate Native job. Both text fields SHALL start blank. Choosing
a visible detection MAY fill its Raw index only and MUST clear the quarter field.
No default quarter label or ordinal count SHALL be inserted. The UI SHALL state
that initial intervals are uncertain and meter/bar phase remain unknown.

The single transient draft MUST belong to the exact global Raw attempt and
capture revision, following that same original content through Move/Swap. Every
action SHALL still check current content/source/placement and original Native
authority. Stale gestures, invalid labels, unavailable Raw and placement pending
MUST NOT admit a job or mutate accepted state. Native refusal and failed durable
save MUST preserve the previous accepted selection/effective delivery.

After valid admission the existing accepted pending/effective path SHALL own the
result independently of Raw discard. Copy/Bank/restart SHALL use the resulting
accepted reference and fresh verification rather than inheriting a Raw draft.
Review actions MUST NOT change scalar BPM, markers, source rate or audio intent.

#### Scenario: A detection is chosen before any quarter coordinate is entered
- **WHEN** the user presses Use detection
- **THEN** only its Raw index is filled and build remains unavailable without valid explicit labels

#### Scenario: Original content moves with an unfinished draft
- **WHEN** the same Raw attempt and capture revision reaches its new PAD
- **THEN** the single explicit draft follows it and actions resolve its current original authority
- **AND** a new equal-digest attempt cannot inherit the old draft or gesture
