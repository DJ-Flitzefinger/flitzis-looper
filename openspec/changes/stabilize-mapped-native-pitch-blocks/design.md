# Actual input and deterministic Native blocks

Reuse MappedNativeInput's immutable original map, clock, canonical checkpoints and
existing request/permit custody. A private typed descriptor qualifies one readable
constant-rate span and its exact frame count before buffer or Native mutation.
Derive pitch from actual input as h/r with Key Lock and h without it. A logical
output checkpoint or copied equal-domain geometry grants no authority.

Bind the descriptor at mint and consumption to the adapter's original actual-input
endpoint, total input serial (including silent prefix), and non-reused mapped
preparation incarnation. Checked next values precede mutation; commit them only
after a successful nonzero render. Zero-frame calls retain the witness. Reset and
same-owner reprepare cannot revive an old descriptor; exhausted counters fail closed.
These witnesses describe existing input custody, not another phase clock.
Use a checked process-local comparison ID created only with the off-realtime
adapter, plus its persistent preparation incarnation. Neither ID nor incarnation
may wrap or be reused; no callback allocation or atomic ID operation is added.
Mapped admission fails closed on identity exhaustion while scalar behavior stays unchanged.

The mapped adapter retains one fixed pending-head pitch while its512-frame input
FIFO is partial. Set the backend pitch immediately before shifting each complete
block, using the value at that block's first input frame. A caller chunk may finish
multiple blocks; each new head uses that chunk's qualified value. Silent physical
birth prefix uses frozen birth pitch without moving the mapped source clock.
Reset clears this scalar together with fixed FIFO state. Existing scalar render
semantics remain unchanged; mapped and scalar inputs cannot mix on an active owner.

Validate descriptor, channel count/lengths, frame count and FIFO capacities before
activation, output lead insertion, pitch changes or writes. Backend failures grant
no successful receipt. Preparation and live actual-input rendering share the same
typed path and retain the same Native and both FIFOs. Pending work checks current
publication/cancellation; effective playback retains immutable original custody
and existing source/OwnACK/retirement checks after later selection/job changes.

Only prepare_owned_mapped_birth_future may newly exercise Key Lock/zero semitones;
its original capture/permit and all other restrictions remain. OrdinaryStartWork
native_required and public mapped/KL/piano/late guards remain unchanged. Later
public integration must reserve Native at birth for mapped Key Lock even when the
initial h/r is unity, unless a whole-map permanent-unity proof exists.

Compare actual PCM and parameter chronology to independent direct C-ABI streams
using512-frame block heads, separate source equations and complete raw prefix/
suffix accounting. Cover irregular caller splits, knots inside/on block boundaries,
silent-prefix phase, worker/live partial FIFO and unity/nonunity return. This law
is block-constant compensation; it does not prove sample-exact tone through a
mixed-rate block, musical alignment, phase ACK, device performance or Human acceptance.
