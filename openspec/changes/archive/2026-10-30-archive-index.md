# OpenSpec archival disposition — 2026-10-30

All 104 changes active at main `dd90d1f6` were archived here on the actual date.
The previous 67 archives retain their original identities. There are no active
change directories after this operation. This is records maintenance, not an
implementation queue, bulk spec merge, completion certificate or Human acceptance.

Current contracts live in [top-level specifications](../../specs/); current
implementation facts remain source-owned. Conflicting historical deltas were not
applied wholesale. Old FULL, SYNC, pre-Rust and model-stage programs are inactive.
The source-map/SYNC scope is retired; ordinary scalar clocks, transport, loops,
grids, accepted constant timing, pitch, source/OwnACK and reader lifetimes remain.

Each row is the explicit old-to-new mapping: the original directory was
`openspec/changes/<id>/`; the linked destination is
`openspec/changes/archive/2026-10-30-<id>/`. Original proposals, designs, tasks,
metadata, nested specs and other files survive. Only navigational references were
repaired for the extra depth and changed destinations. Original complete trees
are independently accessible through each immutable source link below.

Task counts describe the original checklist syntax, not implementation truth.
Every checkbox and FAIL/UNKNOWN/pending statement is retained. Checked tasks do
not prove hearing, device, MIDI, musical/reference, quality, full-216 or other
unfinished gates. An unchecked historical task does not prove functionality is
absent today. No historical experiment becomes a productive backend by archival.

Disposition terms:

- **Historical implementation**: recorded software/evidence, without fresh acceptance certification.
- **Historical implementation; unfinished gates**: delivered portions coexist with explicit uncompleted work or acceptance; consult original tasks.
- **Superseded/retired**: source-map/SYNC scope removed from main; failures and unfinished evidence remain historical. Shared foundations are retained separately.
- **Diagnostic-only**: experiments, probes or planning, with original failures and open matrices retained; no productive adoption implied.
- **Superseded recipe**: only the named policy or storage recipe is superseded; retained contracts/evidence remain scoped.

[Canonical evidence ownership and immutable original reports](2026-10-30-evidence-index.md)
records the eleven full-report retention overrides. Mixed reports remain in docs
until STEP5/6 verify current module destinations; no placeholder report copies or
premature deletion were introduced.
