## Ownership And Admission

One original source-map job uses the existing CompleteSourceReader/ColdLease and
bounded cold pool. Create intent captures the current scalar source origin/period
and explicitly requests manual 4/4 interpretation. The held decoder supplies actual
identity; raw detections remain empty and provenance identifies manual construction.
Edit intent names the exact selected receipt/revision and loaded source rate. Native
restores and source-qualifies that base, validates a new immutable record and stores it
through the existing artifact owner. Existing content/intent/job/private completion,
atomic Config and AssignmentPublicationPlan determine adoption. Old selection stays
effective until success; failure or stale intent cannot replace it.

## Coordinates And Markers

The current effective selection supplies one immutable geometry snapshot to grid,
local-tempo and explicit marker calculations. Native handles viewport bounds, gaps,
meter, subdivision spacing, projection limits and inverse queries. Python never
interpolates source positions. Local source BPM follows actual retained/live source
position; master target remains separate. The editor states that audio remains scalar.

Explicit map snapping uses the versioned later-tie policy then final loaded-frame
rounding. Scalar nearest-even behavior is untouched. Explicit bar operations require
supported quarter-note 4/4 throughout their interval and materialize source markers
through the existing guarded loop publication path. Map acceptance alone cannot
recompute an old automatic loop or move persisted markers.

## Correction And Recovery

Moving one musical beat to a source sample may insert a local accepted anchor; raw
predictions and unsupported coverage are preserved. A separate signed translation
moves the whole map without changing musical intervals or master time. Both record
exact sample/rate intent, raw provenance, parent revision and inverse correction
data. Undo applies the captured inverse as another validated immutable revision.
No second map/history registry is introduced. Corrected references retain delivered
Copy/Pair/Bank/history and fresh-process source verification semantics.

Viewport and editable control snapshots are keyed by content, actual source and map
revision. Pending edits do not masquerade as current audio. Bounds or unsupported
coverage refuse explicitly, preserving existing selection/markers. No automatic
repair of unknown count, downbeat, meter or uncertain onset is implied.
