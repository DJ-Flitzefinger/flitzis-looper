## Why

Qualified mapped starts must retain their nonzero-pitch refusal until Native output
covers the same intended output-time range as dry playback. Constant h permits
internal preparation; correct input chronology alone does not prove alignment.

## What Changes

- Keep public nonzero mapped admission refused and callback feedback truthful.
- Prepare qualified constant-h mapped input internally through existing Native
  ownership, silence before the exact origin and genuine actual-read receipts.
- Verify the complete uncropped Native stream without claiming output alignment.
- Refuse mapped delayed reconstruction before unrelated scalar endpoint comparison,
  preserving preceding audio, original targets and atomic groups.

## Non-goals

No new clock, scheduler or pipeline. Productive mapped Native activation, real
future/output-time ownership, continuous adoption, automatic fullmix maps, all
rates, variable h/r, delayed starts and both genuine start policies remain FULL
Goal obligations, as do every original resource/music/device/Human/final gate.

## Realtime

Native construction and warm-up remain off realtime. Callback code uses fixed
copied spans and original owners, with final retirement off realtime. No
allocation, I/O, GIL, locks or unbounded work is added.
