## Why

The selected Beat This worker already performs real, reference-checked inference,
but the application's original-fullmix review command still acquires QM-only Raw
data. SYNC therefore lacks a genuine complete Beat This capture connected to the
existing source/map lifecycle. Another manual-label or QM-only increment would
leave this selected-backend integration missing.

## What Changes

- Connect the original-fullmix review command to the existing verified Beat This
  worker on the existing bounded cold map lane, with current original custody.
- Preserve complete beat/downbeat timestamps and both logit arrays in a distinct,
  strict versioned Raw capture. Keep old QM Raw and accepted map V1/V2 compatible.
- Reuse the private Raw artifact, single review lease, independent accepted-map
  job, immutable publication and existing cancellation/retirement owners.
- Keep backend capture, worker orchestration and map interpretation in focused
  modules; add only thin engine entry points.

## Non-goals

This does not certify inferred musical count/meter/coverage, switch ordinary
pad-load BPM analysis before B2 acceptance, add a backend Settings selector, use
Drum D by default, repair the renderer, or complete continuous SYNC. Existing
manual/TAP/saved analysis and productive admission guards remain authoritative.
No model setup/download, inference or heavy work is added to startup or callback.
