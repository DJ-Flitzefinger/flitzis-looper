## Decision

The public Load Audio path expresses explicit import. Its managed-path guard will admit only a typed StemArtifact whose leaf is one of vocals.wav, melody.wav, bass.wav, drums.wav or instrumental.wav. This exception does not apply to auto or restore intent. Existing traversal, reparse, filename, typed namespace and exact-object checks remain mandatory.

The existing ProjectAssets source pin must protect the input before worker submission. The unchanged ColdTransaction import captures byte-exact audio into an independent canonical original. Its source reader and directory guards remain responsible for source stability. Only the existing native adoption acknowledgement can complete the PAD replacement; Config never records a stem generation as its original.

Input generation cleanup may proceed after capture and final input readers release. The imported original must remain valid independently. A rejected or failed attempt must preserve the previous copied source and sibling assignments. No filesystem or allocation work is added to the callback.
