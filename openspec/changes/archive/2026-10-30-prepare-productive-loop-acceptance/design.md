# Human-run evidence, independent offline comparison

The opt-in measurement route runs the existing application and control paths in
an isolated private workspace project. Actual native CURRENT source and callback
acknowledgement establish accepted authority; caller configuration and historical
tickets cannot replace it. Explicit assessments retain independent musical-unit,
origin, error and acceptance assertions. Missing or stale ownership blocks usable
evidence rather than relabeling a provisional value.

Record source and configuration identities, complete accepted metadata and
revision, native binding and clock snapshots, and physical H versus compatible
musical P. Control intent and estimated timing are labeled as such wherever the
native interface cannot prove effective audible state. No polling changes audio
progression. Capture is performed by the human's recorder outside the callback.

Offline scans find signal features without candidate-predicted search windows.
Explicit feature/cycle association has provenance; association from knowledge of
authored diagnostic fixtures is not general independent musical annotation.
Measured capture deltas convert through an independently established
output-frames-per-capture-frame clock relationship and source rate. Unknown clock
relationships or excessive uncertainty remain inconclusive. Constant seam/DSP
offsets cancel only for recurrence of the same feature under fixed conditions;
absolute inter-pad and transition alignment remain separate measurements.

The numerical limit remains one loaded frame of unwrapped musical error at 75
and 1000 cycles. Discrete output sampling, threshold sensitivity and uncertainty
are reported independently, never concealed in a weaker gate. Reports retain
device/listening gates as open; passing schema checks is not acceptance. Human
listening records bind the actual run/capture and uninterrupted duration of at
least 1800 seconds, with explicit observer and audible observations. Private
sources, captures, project configuration and large evidence stay outside Git.

The productive route resolves private plan paths against the explicit workspace,
independently of the shell working directory. A source-specific PCM budget uses
genuine loaded frames/rate/channels and the frozen reference duration. Normal
constant-timing preparation and saved restoration retain their 512 MiB policy;
the route may opt into a finite budget no greater than 1 GiB. Native capacity
checks remain authoritative. The budget follows captured/prepared/current runtime
ownership so exporting accepted evidence re-verifies the same full source within
that bound. It is not serialized as accepted evidence or a restoration permission.
No resource policy or preparation work is added to the realtime callback.

Actual device/listening acceptance is deferred to the end of the authorized
pre-port program. Its pending status does not block separately authorized later
preparation stages; automated/numerical and realtime/source-identity requirements
still apply. Deferral is a scheduling decision, never a passed G3 receipt.

Human guidance explains listening versus recording, reports preparation failure
and READY explicitly, identifies UI pad #1 as native pad 0, and keeps all actual
acceptance gates open. Restarting creates new observations but preserves saved
project controls; a modified diagnostic project needs a freshly prepared packet.
