# Design

Use the existing placement transaction and publication permit. Immutable checks establish the exact source, physical cut and warmed SPSC reserve readiness. Only the callback consumes those ready handles; its worker can only add ready handles and release recycle capacity. A successful claim applies the preflighted exchanges without a new fallible worker-status check, then publishes storage and physical controls.

An unrelated writer defers the original payload before any live Native, FIFO, productive/read history or EQ mutation. A cancelled permit rejects it at the same boundary. Preparation, allocation and destruction remain outside rendering. Tests acquire a real writer or cancel the original permit after callback preflight and compare existing DSP owners, history and independent rendered PCM before retry or rejection.
