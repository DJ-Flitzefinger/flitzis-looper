## Why

Source-qualified selected maps now survive persistence, arrangement and fresh restore,
but the Loop Editor still uses only scalar coordinates and has no map admission or
correction action. A saved map must become a usable, explicitly chosen editor mode.

## What Changes

- Create a manual quarter-note 4/4 map from explicitly captured source scalar timing
  on the existing source-qualified Native worker. Never promote legacy analysis lists
  into detector evidence or claim automatic musical acceptance.
- Share Native map coordinates for bounded grid drawing, snapping, explicit bar loops
  and current local source BPM. Keep master target and scalar audio clearly identified.
- Add separate sample-domain beat positioning, signed whole-map translation and
  undoable immutable corrections through the existing selection/Config/asset owners.
- Preserve physical markers until an explicit marker/bar/resnap action. Materialize
  variable-map bar edits as physical marker intent instead of automatic scalar loops.

## Non-goals

This delivery does not activate map-driven audio, SYNC, detector defaults or refinement.
Independent beat-count/downbeat repair and their full B4 acceptance remain required
later. No B2 musical, P6 resource, device, hearing or Human gate is claimed.

## Realtime Constraints

Construction, source hashing, immutable publication and corrections run off realtime
on the existing bounded Native job. Python renders bounded Native projections and
sends small editing intent; no second interpolation, scheduler or callback work.

## Contract Lineage

This is an implemented subset of `share-editor-beatmap-coordinates` on the delivered
source-beatmap foundation and `select-persisted-source-beatmaps`. Manual/exact-fixture
editor engineering is distinct from the still-open automatic measured-quality gate.
