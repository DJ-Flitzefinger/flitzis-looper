pushes to `performance-upgrade` and automatic creation of the next chat; historical
main-publication/manual-successor/full-port limits do not govern this assignment.
No Goal object is requested. Expand the step count when evidence requires a
separate coherent fix; never force an incomplete change through a milestone.

perform Systems PRE/frozen POST, Methods review and one independent final-diff
