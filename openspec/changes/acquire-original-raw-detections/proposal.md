## Why

The Source Map editor can select and correct accepted geometry, but cannot yet
acquire complete original detector evidence through its production owner. Long
fullmix sources need genuine complete acquisition before quarter-note counts,
meter, coverage and a usable musical map can be reviewed. The analysis-purpose
diagnostic export and an invented accepted scalar seed cannot supply that path.

## What Changes

- Add a typed, unverified raw acquisition result to the existing Native map job,
  cold lane, immutable artifact birth and private loader-completion machinery.
- Analyze the complete admitted original full mix, retaining actual mono/analyzer
  provenance and original binary64 QM detections with bounded staged memory.
- Provide one transient review slot and a bounded inspector in Source Map, with
  truthful queued, running, cancellation/retirement, failure and review states.
- Preserve accepted map intent, selection, persistence, playback and SYNC across
  every raw operation. A raw candidate cannot authorize any musical coordinate.

## Non-goals

No automatic quarter/count/meter/coverage acceptance, raw grid or audio adoption.
No durable raw receipt, Copy/Bank/restart restoration, new analysis pipeline,
Beat This default cutover, new detector survey, Native output alignment or full
SYNC/resource/music/device/Human acceptance. Those full-Goal obligations remain.

## Realtime

Hashing, complete PCM reads, conversion, QM, serialization and artifact retirement
remain on existing non-realtime owners. The callback receives no raw geometry,
candidate, inference, I/O, new allocation or heavy final-owner destruction.
